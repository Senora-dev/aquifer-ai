# Evaluation environment (Terraform)

A self-contained AWS environment for evaluating Aquifer end to end, managed by Terraform so it
can be removed completely with one command. It mirrors the production CDK stack in
`infrastructure/` (same application code, same security model) and adds a tiny SSM-only test
client so you can reach the internal MCP endpoint from your laptop.

> Production deployments use the CDK stack ([docs/deployment.md](../../docs/deployment.md)).
> This environment is for evaluation and testing; both run the same Lambda and MCP code.

## One-time prerequisites

AWS CLI v2 (logged in), Terraform ≥ 1.6, Docker (running), GitHub CLI (`gh auth login`),
Python 3.11+, and the AWS Session Manager plugin
(`brew install --cask session-manager-plugin`). `./aquifer-test check` verifies all of them,
plus Bedrock model access in the region.

## From zero to a tested deployment

```bash
cd deploy/terraform
./aquifer-test check        # tools, AWS login, OpenSearch + Bedrock in the region
./aquifer-test seed         # 3 private GitHub repos with synthetic data, a real issue and PRs
./aquifer-test configure    # writes terraform.tfvars (repos, region, auto-detected Claude model)
./aquifer-test plan         # builds artifacts, shows every resource to be created
./aquifer-test up           # applies that plan, stores the GitHub token, ingests, waits
./aquifer-test test         # end-to-end MCP checks + idempotency check
./aquifer-test test-updates # pushes a change + a deletion to GitHub, re-ingests, verifies, reverts
./aquifer-test connect      # forwards the MCP endpoint to localhost and prints the Claude Code command
./aquifer-test down         # terraform destroy (asks first)
```

`up` takes ~10–15 minutes (OpenSearch Serverless collection creation dominates).

## What gets created

| Area | Resources |
| --- | --- |
| Network | VPC, 2 public + 2 private subnets, IGW, 1 NAT gateway + EIP, route tables; Bedrock runtime, Secrets Manager and SQS interface endpoints; S3 gateway endpoint; security groups (endpoints, ingestion, MCP, NLB, test client) |
| OpenSearch Serverless | VECTORSEARCH collection (standby replicas off), encryption/network/data-access policies, VPC endpoint |
| Ingestion | SQS queue + DLQ, S3 state bucket, GitHub-token secret, Discovery and Worker Lambdas (arm64) + IAM roles, SQS trigger, 15-minute schedule, log groups, DLQ and error alarms |
| MCP server | ECR repository, ECS cluster, Fargate task (arm64, non-root, read-only FS) + roles, MCP token secret, internal NLB + listener + target group, log group |
| Test client | t4g.nano in a private subnet, no public IP, no SSH, SSM only (`-var create_test_client=false` to skip) |

Nothing is reachable from the internet. **Cost while running: roughly $0.40/hour (≈ $10/day)**,
mostly OpenSearch Serverless (1 OCU). After `down` the cost is zero.

## What the tests check

`./aquifer-test test` runs [`tests/e2e.py`](tests/e2e.py) through a real MCP client:

- requests without a token / with a wrong token get `401`
- every repository was ingested (`list_sources`)
- `find_related` returns explicit relationships with the real file, line, commit SHA and
  line-anchored GitHub permalink, supported by both descriptors
- LLM extraction from the real GitHub issue (`llm_extracted`, `grounded`, line of the mention)
- Terraform module references across both repositories; similar names not confused; unknown
  entities return `evidence_status: none`; repository filters isolate results
- semantic search ranks the ADR first; `get_document` returns the exact lines; merged vs open PR
  state
- a second ingestion indexes nothing (skip-unchanged) and nothing fails

`test-updates` additionally proves update and deletion propagation against real GitHub commits.
The JSON report is written to `.build/e2e-report.json`.

## Using it with your own agent

```bash
./aquifer-test connect
claude mcp add --transport http aquifer-test http://127.0.0.1:18080/mcp \
  --header "Authorization: Bearer $(./aquifer-test token)"
```

## Notes

- The GitHub token is copied from `gh auth token` straight into Secrets Manager; it never enters
  Terraform state. The MCP token is generated by Terraform (local state — keep it private).
- `AQUIFER_REGION`, `AQUIFER_NAME` and `AQUIFER_EXTRACTION_MODEL` override the defaults.
- Logs: `./aquifer-test logs worker|discovery|mcp [minutes]`. Status: `./aquifer-test status`.
